# Gevoelskompas

Drie keer per dag inchecken met de vier B's: bang, boos, blij en bedroefd. Met notities, een overzicht, herinneringstijden en een PDF-samenvatting om te delen of te printen.

Open de app op iPhone in Safari en kies **Deel › Zet op beginscherm**. Alle check-ins blijven op het toestel zelf; er gaat niets naar een server.
